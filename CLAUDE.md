# micropub-publisher

Micropub, media, IndieAuth, and editor service for martinemde.com: SvelteKit 3 / Svelte 5
(runes) on Cloudflare Workers. Human-facing docs are in [README.md](README.md) and
[docs/](docs/); keep them current when behavior changes, and put new reference material
in `docs/`, not the repository root.

- Use **pnpm**, with Node and pnpm versions from `mise.toml`. Commit `pnpm-lock.yaml`.
- Before pushing, run `pnpm run lint`, `pnpm run check`, `pnpm run test`, and
  `pnpm run build`. Run `pnpm run conformance` when changing Micropub behavior.

## Code

- SvelteKit 3 options, including the adapter and CSRF policy, are passed to
  `sveltekit(...)` in `vite.config.ts`; there is no `svelte.config.js`.
- Environment variables are declared in `src/env.ts` and imported from
  `$app/env/private` or `$app/env/public`. Tests change them through `privateEnv` and
  `publicEnv` in `src/lib/test-helpers.ts`.
- Import library modules as `#lib/…` with explicit file extensions. Import `.svelte`
  components by relative path instead, because `svelte-check --tsgo` does not
  type-check props through `#lib`.
- `scripts/cloudflare-adapter.mjs` wraps the adapter's Worker in
  `scripts/cloudflare-worker.mjs`, which routes every request through one Durable
  Object. Adapter 8 passes no per-request `platform`, so that object registers its
  storage on `globalThis` for `src/lib/server/state.ts`.
- SvelteKit 3 blocks an external `redirect()` unless `{ external }` is passed.

## Post format contract

The front matter written by the publisher (see [docs/micropub.md](docs/micropub.md#post-files))
is read back by martinemde.com. A change to it must land in both repositories:
martinemde.com keeps fixtures generated by this serializer in
`src/lib/fixtures/publisher/`, to be regenerated when the contract changes.
